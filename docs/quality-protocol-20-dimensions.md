# Twenty independent expert review lenses

The project does not award a 20/20 grade because automated validation passes. An executable audit (tools/quality_audit_20.py) separates tested invariants, observed publication blockers, and criteria demanding an expert.

The dimensions are: (1) source integrity and metadata; (2) learning objectives and audience; (3) architecture; (4) learning progression; (5) grammar and naturalness; (6) vocabulary; (7) active speaking; (8) listening/media; (9) reading-to-speaking; (10) pronunciation; (11) item quality; (12) scoring validity; (13) teacher guides; (14) cultural inclusion; (15) DOCX semantic navigation; (16) visual page design; (17) image accessibility; (18) EPUB navigation; (19) cross-format fidelity; and (20) rights, sources, publication approval.

## Rules for the editorial release

- Identify each defect by file and location, reproduce it where possible, correct it in the authoritative source, and independently verify the result. Do not weaken a QA threshold to manufacture success.
- Correct true accessibility issues, never fabricate image descriptions, rights or references.
- Treat media-link inspection, third-party copyright approval, a full grammar/factual line edit, real-world learner testing, accessibility testing and physical print proof as separate required work.
- Keep the original Master Speaking manuscript unchanged; changes to working Word proofs should be reproducible. Keep grammar-book source edits in build_spec and regenerate both Student and Teacher editions.
- An approved final release needs evidence for all 20 dimensions. Any unresolved BLOCKER prohibits the claim of commercial publication readiness. Machine PASS does not automatically qualify a subjective quality category.
